# brainX - AI CMO Website

> An AI CMO that runs your entire marketing team.

A pixel-perfect, feature-complete clone of [brainxapp.com](https://www.brainxapp.com/) built with pure HTML, CSS, and JavaScript.

## 🚀 Live Demo

👉 [View Website](https://raeesvsl1-png.github.io/Brainx)

## ✨ Features

- **Dark Cyberpunk Aesthetic** — Neon green (#12f94b) on deep black with glowing effects
- **CRT Mode Toggle** — Retro scanline + phosphor flicker effect (saved to localStorage)
- **Interactive Prompt Demo** — 3 switchable marketing campaign scenarios with live agent output
- **8-Agent Constellation Diagram** — Orbital network with hover details (X, LinkedIn, Reddit, SEO, GEO, Influencer, Writer, Analytics)
- **Workflow Steps** — Terminal-styled 3-step CMO workflow cards
- **Cost Comparison** — \,500/mo (5 hires) vs brainX (1 AI agent)
- **Roadmap** — 3 acts of AI marketing evolution
- **Slack Simulator** — Interactive approval workflow preview
- **FAQ Accordion** — Smooth expand/collapse
- **Early Access Modal** — Full form with channel selection + confirmation state

## 🛠️ Tech Stack

- HTML5 (Semantic)
- CSS3 (Vanilla — no frameworks)
- JavaScript (Vanilla ES6+)
- Google Fonts: Inter + JetBrains Mono
